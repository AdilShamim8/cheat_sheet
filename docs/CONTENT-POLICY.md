# Content policy

1. Facts are verified against primary sources at the lastUpdated date on each page.
2. Version histories end at the current stable release; future releases are never asserted as fact.
3. Usage statistics cite the survey and the date; rankings go stale within months.
4. Code samples are production-shaped and tested for syntax.
5. Speculative entries are removed rather than hedged (see PHP 9.0 removal in Nov 2026).
